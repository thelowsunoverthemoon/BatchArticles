## Articles on Batch Script

A lot of knowledge on Batch Script is buried away in old Google Groups or forums that are shutdown. In fact, even LLMs get obscure details wrong. I wanted to write tutorial articles to explain these tips / tricks and provide links so that this knowledge isn't lost. Unlike the modern programming languages of today's world, Batch is full of archaic hacks and tricks that make it interesting to write and learn.
